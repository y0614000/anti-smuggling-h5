# 第一关「行李检查」游戏设计

## 1. 关卡目标

玩家扮演海关查验小助手，在 60 秒内拖动侦查放大镜检查旅客行李，找出 3 件可疑物品，并选择正确的处理方式。完成后获得专属道具「侦查放大镜」。

关卡需要传达的核心知识：不携带来源不明或涉嫌濒危野生动植物制品，不隐瞒应申报物品，发现可疑线索时主动申报并配合海关查验。

## 2. 核心玩法

1. 玩家按住并拖动放大镜，在打开的行李箱中移动。
2. 镜片经过热点区域时，物品会被局部放大并出现柔和金色光圈。
3. 在热点内停留约 0.6 秒后发现线索，点击物品进入判断弹窗。
4. 玩家从「正常物品」「需要申报」「可疑走私物品」中选择处理类型。
5. 判断正确后线索进入右侧收集槽；错误时给出简短知识提示，可重新选择。
6. 收集并正确判断 3 件可疑物品后通关。

## 3. 行李箱内容

| 物品 | 类型 | 正确选择 | 知识提示 |
| --- | --- | --- | --- |
| 象牙色雕花手镯 | 可疑物品 | 可疑走私物品 | 疑似象牙等濒危野生动物制品，应交由海关进一步查验。 |
| 疑似珍稀动物皮制钱包 | 可疑物品 | 可疑走私物品 | 来源不明的野生动物皮制品不能随意携带入境。 |
| 未申报的热带水果 | 应申报物品 | 需要申报 | 水果等动植物产品应主动申报并接受检疫检查。 |
| 衣物、旅行日记、相机、玩具、洗漱用品 | 普通物品 | 正常物品 | 合理自用且符合规定的旅行用品可正常携带。 |

## 4. 页面布局

| 区域 | 内容 |
| --- | --- |
| 顶部 | 返回按钮、标题「第一关·行李检查」 |
| 状态栏 | 可疑物品 `0/3`、倒计时 `60` |
| 主操作区 | 海关传送带、打开的蓝色行李箱、可拖动放大镜 |
| 右侧 | 3 个线索收集槽，未发现时显示问号 |
| 底部 | 操作提示、提示按钮、IP 引导角色 |

## 5. 状态流程

| 状态 | 表现 |
| --- | --- |
| 引导 | IP 指向行李箱，提示「拖动放大镜，找出3件可疑物品」 |
| 查验中 | 放大镜跟随手指移动，镜片内显示放大区域 |
| 发现线索 | 热点发光、轻微弹跳，弹出物品判断卡片 |
| 判断正确 | 星光动画，物品缩小飞入右侧收集槽，进度加一 |
| 判断错误 | 卡片轻微晃动，显示知识提示，不直接结束游戏 |
| 时间结束 | 显示已发现数量，并提供「重新挑战」按钮 |
| 通关 | 金色星光与彩带，展示「获得：侦查放大镜」 |
